# Supplemental dependency notices

`glib-COPYING` is the unmodified LGPL 2.1 text from
<https://github.com/GNOME/glib/blob/2.90.1/COPYING>.
Homebrew's GLib installation does not include this file, so the macOS packager
uses this copy when collecting notices for that library. Other installed
package notices are copied from the supplied build dependencies.
