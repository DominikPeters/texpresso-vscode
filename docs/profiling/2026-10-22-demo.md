# Rich preview demo and dashed strokes — 22 October 2026

The default local demo is now `showcase.tex`, a three-page document with linked
cleveref equation/figure/table/proposition references, citations from
`showcase.bib`, a TikZ Bézier diagram, and a bibliography. The original minimal
fixture remains unchanged for SyncTeX regression coverage. New sample filenames
preserve edits to the earlier demo documents.

The launcher prepares auxiliary files and the bibliography with installed
`latexmk -xelatex`, then enables automatic reference reruns. Bibliography edits
use External Compile and Refresh. It neither downloads packages nor engines.
The local XeLaTeX/BibTeX preparation completed without unresolved-reference or
citation warnings.

The diagram exposed a native compatibility failure: dashed paths copied dash
entries into a bare stack `fz_stroke_state`, but current MuPDF uses flexible-array
storage. On macOS the fortified memcpy detected the overflow and trapped when
rendering the second page. The native interpreter now allocates dash storage
using MuPDF's API, uses copy-on-write when a display list retains the stroke,
and releases the owned state on normal and exceptional exits. All six PDF
stroke operators use the same ownership path. A native regression checks dash
arrays and retained-state mutation; a real-engine regression renders and edits
later-page dashed/dotted TikZ paths in PNG and SVG.

Final validation rendered all three showcase pages through the compact bundled
engine in both PNG and SVG. Every page's interaction metadata matched across
codecs, and every internal reference/citation URI had a destination in the
three-page document. The PNG pages were visually inspected, including the dashed
control polygon, reference table and bibliography. The separate early-input
VS Code follow-up also verified hidden normal status and a stable Auto label
at every measured paint in four production webviews.
