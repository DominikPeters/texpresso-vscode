# Reducing SVG host processing

The extension now tokenizes each fresh SVG once. Previously it parsed the native
SVG, rewrote encounter-order font IDs into outline-derived IDs, and then parsed
the complete rewritten document a second time. It now remaps the original indexed
spans through those controlled rewrites. Removed duplicate glyph definitions also
update ancestor child counts and positions. Normalized bytes and splice operations
remain identical.

Glyph outline SHA identities are reused through a bounded LRU. Its estimated
string/entry budget is 256 KiB; captures are copied into owned UTF-16 storage so
small cached outlines cannot retain an entire SVG's backing store. Each new frame
still goes through the complete structural parser. The browser's strict element,
attribute, reference and geometry validation remains unchanged. Hash collisions
are still checked against exact outlines inside each document.

## Recorded-frame benchmark

Local arm64 macOS, Node host only, using the already-recorded native SVG corpus in
`artifacts/profile-svg-diff`. Each fixture has four frames: original, inserted
letter, backspace/undo, and a new earlier font. Ten warm-up rounds followed by 80
measured rounds produce 320 samples for each processor/fixture. Baseline and new
processor order alternate each round. This isolates extension work; these are not
end-to-end editing latencies.

| Fixture | Canonicalization before/after (ms) | Canonicalization + diff before/after (ms) | Total p95 before/after (ms) |
| --- | ---: | ---: | ---: |
| Sparse text | 0.842 / 0.565 | 0.885 / 0.608 | 2.729 / 1.943 |
| Dense text | 2.582 / 1.802 | 2.785 / 1.994 | 4.969 / 3.687 |
| Packed text | 4.312 / 3.109 | 4.904 / 3.606 | 13.484 / 11.138 |
| TikZ | 2.656 / 1.707 | 2.916 / 1.902 | 3.609 / 2.606 |

Median combined host work falls 26–35%. The diff implementation itself is unchanged;
its smaller measured times can reflect allocation and garbage-collection effects.
The remaining parser, reference rewriting, and comparison still process a whole
SVG. Native SVG export, compiler work, IPC delivery, and browser rendering were
not changed by this optimization.

The benchmark independently reparses every normalized output, checks that the
remapped tree matches exactly, and compares normalized bytes and patch operations
with the baseline. Separate unit tests cover nested groups/references, multiple
definition blocks, duplicate glyph removal, conflicting IDs, time limits and
invalid input after cache warming. Structural, node-count and depth budgets remain
in force; failure still falls back to the existing full-image path.

## Reproduce

Save a compiled baseline before changing `src/svg-patch.ts` (the measured baseline
source is unchanged since commit `7560100`), then run:

```sh
npm run compile-tests
node scripts/profiling/svg-host.cjs artifacts/profile-svg-diff /tmp/texpresso-svg-baseline.js
```

Without the final argument, the script measures only the current processor. It
uses local recorded frames and opens no engines/windows. To regenerate the corpus
using the existing local TeX Live installation:

```sh
TEXPRESSO_BINARY="$PWD/native/.bundles/darwin-arm64-preview/bin/texpresso" \
  node scripts/profiling/svg-diff.cjs artifacts/profile-svg-diff-new
```

Use a new empty output directory. The corpus generator does not download packages.
The recorded host comparison is saved in the ignored local file
`artifacts/profile-svg-host/summary.json`.
